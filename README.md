Student Marks Analysis Using NumPy

Day 1 – Assignment 1

Project Description

This project is based on Python programming using the NumPy library. It performs basic student marks analysis for 4 students across 5 subjects.

Objectives

- Generate a marks matrix for 4 students and 5 subjects.
- Calculate total marks of each student.
- Calculate the percentage of each student.
- Find the average marks in each subject.
- Calculate the standard deviation of each subject.
- Find the highest marks in each subject.
- Identify the student who scored the highest marks.
- Check the Pass/Fail status of students.

Technologies Used

- Python
- NumPy

Installation

Install NumPy using the following command:

pip install numpy

How to Run

1. Open the project in VS Code.
2. Open the Python file.
3. Run the program using the Run button or terminal.

Output

The program displays:

- Marks Matrix
- Total Marks
- Percentage
- Average Marks
- Standard Deviation
- Highest Marks
- Student Number
- Pass/Fail Status
